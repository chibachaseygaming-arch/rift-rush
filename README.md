# Rift Rush

Rift Rush is a fast neon arena survival game. Dodge enemy swarms, defeat bosses, collect Rift Shards, and build permanent upgrades that carry across runs.

## Play online

- GitHub Pages: https://chibachaseygaming-arch.github.io/rift-rush/
- Original public site: https://rift-rush.chibachaseygaming.chatgpt.site

## Features

- Endless waves with increasingly difficult enemies
- Boss battles and temporary mid-run upgrades
- Permanent upgrades saved in the browser
- Accuracy upgrades in both upgrade menus
- Rift Shards earned by playing
- Keyboard, mouse, and mobile touch controls
- Responsive neon interface for desktop and phones

## Controls

- **Move:** WASD or the on-screen joystick
- **Aim:** Mouse or touch
- **Shoot:** Hold the mouse button or the on-screen fire control
- **Dash:** Space or the on-screen dash button
- **Pause:** Escape

## Run locally

Rift Rush requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local address printed in the terminal.

## Build and test

```bash
npm test
```

Progress and permanent upgrades are stored with `localStorage` in the player's browser.

## Custom `.com` domain

The GitHub Pages deployment supports a custom domain after its owner connects a purchased domain in the repository's Pages settings.
